How to use:

Enter two JavaScript regular expressions (without the surrounding slashes) and click "Check Equivalence". The tool determines whether the two expressions match exactly the same strings. Otherwise, example strings are shown that match either expression but not both.

Examples:

  • a|aa and a{1,2} are equivalent
  • a+ matches a subset of a*
  • ^a{0,4}$ and ^a{2,6}$ match some common strings
